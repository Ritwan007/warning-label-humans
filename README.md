Entry for the [make.fun](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) competition "Warning Label for Humans: One Line, Big Laugh".

`main.ts` writes one single-line safety warning label for every human being (113 characters) to `/output/entry.txt`, deterministically, with no randomness and no network access.

## Run

```sh
node main.ts
cat /output/entry.txt
```
